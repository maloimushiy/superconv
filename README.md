# Super-Convergence

Проверка идеи [Smith & Topin](https://arxiv.org/abs/1708.07120): можно ли обучить сеть быстрее с помощью одного цикла learning rate.

LeNet-подобная CNN на MNIST, PyTorch. Разбиение: 55 000 train / 5 000 validation / 10 000 test. Batch size 512, SGD, weight decay 0,0005. Три seed: 17, 42, 103.

## Результаты

Запуск на A100 80 GB в DataSphere. Среднее ± стандартное отклонение между seed:

| Режим | Эпохи | Test accuracy | Время обучения |
|---|---:|---:|---:|
| Baseline | 85 | 99,057 ± 0,045% | 17,84 с |
| Baseline, промежуточные веса | 12 | 98,500 ± 0,115% | 2,54 с |
| 1cycle, пик LR = 0,1 | 12 | **99,147 ± 0,029%** | **2,51 с** |
| 1cycle, пик LR = 0,02 | 12 | 98,840 ± 0,010% | 2,51 с |

1cycle дал немного более высокую точность за 12 эпох вместо 85. Измеренное время обучения сократилось в 7,1 раза; при одинаковых 12 эпохах выигрыш составил 0,647 п.п. Это проверка идеи на MNIST, а не точное воспроизведение статьи. Время не включает валидацию и подготовку окружения.

Baseline использует inverse decay от LR = 0,01 и momentum = 0,9. В 1cycle LR растет до пика за 5 эпох, возвращается к 0,01 за следующие 5 и снижается до 0,00001 за последние 2. Momentum меняется 0,95 → 0,8 → 0,95.

## Запуск

```bash
pip install -r requirements.txt
python train.py
```

Модель и обучение находятся в `train.py`. Метрики сохраняются в `results/`; результаты завершенного запуска лежат в [results.csv](results.csv). Они получены до сокращения служебного кода, с теми же моделью и настройками. Ноутбук с разбором добавим отдельно.
